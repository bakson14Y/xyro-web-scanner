# XYRO 2.0.0

Общий локальный движок без ИИ для Android (arm64-v8a / x86_64), Windows x64 и Linux x64.

- Исправлена причина Android panic в Dalfox: standalone-процесс использует закреплённые корневые CA и проверку TLS без JNI. Проверка сертификатов не отключена.
- Nuclei HTTP, DAST и SSL работают отдельными этапами. В приложение включён полный снимок nuclei-templates 10.4.6: все 251 DAST-шаблон (включая все имеющиеся годы CVE) и 38 SSL-шаблонов сохранены без изменения подписей.
- Добавлены импорт JSON/HAR-запросов, DAST по телам POST/JSON, сбор форм по явной настройке, категории проверок, управляемый OAST через собственный Interactsh.
- Censys Platform API v3: пассивные домены и IP, пагинация, ограничения квоты, скрытие токена. Нужен пользовательский Personal Access Token с доступом к API.
- Механические агенты: ограниченная очередь, зависимости этапов, разделение целей, адаптация по памяти, продолжение незавершённых задач и сохранение результатов при ошибках.
- Повторное выполнение Nuclei-находок с отдельным статусом воспроизведения. JWT HMAC проверяется локально. Сравнение ролей использует две сессии, гостевой контроль и заданный маркер данных.
- Интерфейс показывает план покрытия, причины пропуска, задачи агентов и журналы. ZIP-отчёт включает HTML, CSV, SARIF и вложенные журналы с удалением секретов настроек.

## Реальные границы покрытия

194 DAST-шаблона XSS требуют Chromium: файлы входят в снимок, но не исполняются этой сборкой ни на Android, ни на ПК. Для XSS отдельно работает Dalfox. Code, file, headless, локальные и DoS-шаблоны не запускаются. OAST, TCP/DNS/JavaScript, шаблоны повышенного воздействия и слабые upstream matchers требуют отдельных настроек. Некоторые протоколы выполняют прямые соединения и используют порты из шаблона.

Все существующие в снимке папки dast/cves включены: 2018, 2020, 2021, 2022, 2024. Вымышленные годы и категории не добавлены. Наличие CVE-шаблона не означает универсальный детектор класса уязвимостей. IDOR, OAuth, CSRF и бизнес-логика требуют контекста; отсутствие CSRF-поля — наблюдение, а не подтверждённая эксплуатация.

Android APK собран с CI debug-подписью. Если установленная версия подписана другим ключом, экспортируйте отчёты перед переустановкой. Полный аудит большой цели может не уложиться в один бюджет: продолжение сохраняет завершённые задачи. Одинаковый движок не означает одинаковую скорость устройств.

Исходники зависимостей закреплены в tools.lock.json. Контрольные суммы приложений — SHA256SUMS.txt. Все release jobs должны пройти локальные HTTP/HTTPS/DAST fixtures и проверки упакованных приложений; сторонние сайты для тестов не сканируются.
