## XYRO 1.5.1 — исправление редиректов

- Исправлен сбой recon `ValueError: Вне заданной области` при перенаправлении на другой origin. Теперь результат содержит информационную запись с исходным и конечным URL и объяснением следующего шага; остальные начальные URL продолжают обрабатываться.
- Исправлена передача HTTP-заголовков при разрешённых редиректах. Пользовательские заголовки сохраняются; заголовки ответа больше не подставляются вместо заголовков запроса.
- Область проверки остаётся явной: схема, хост и порт. Для проверки конечного сайта укажите его полный URL; для проверки обоих адресов добавьте конечный адрес в дополнительные начальные URL.
- Те же 15 модулей и встроенные шаблоны Nuclei на Android, Windows и Linux. Без ИИ и внешнего сервера-исполнителя.

### Скачать

- **Android 8+, ARM64/x86_64:** `XYRO-1.5.1-Android.apk`.
- **Windows x64:** распакуйте весь `XYRO-1.5.1-Windows-x64.zip`, запустите `XYRO.exe`.
- **Linux x64:** распакуйте `XYRO-1.5.1-Linux-x64.tar.gz`, запустите `./XYRO/XYRO`.
- Контрольные суммы: `SHA256SUMS.txt`.

APK подписан временным debug-ключом CI. Сначала экспортируйте отчёты: если Android не принимает обновление из-за другой подписи, потребуется удалить предыдущую установку. Windows EXE не подписан Authenticode.

### Проверка

Публикация зависит от регрессионных тестов редиректов и остальных тестов ядра, самопроверок упакованных Windows/Linux-приложений и установленного APK на эмуляторе Android API 35 x86_64. Самопроверки приложений включают разрешённый редирект с заголовком сессии и внешний редирект с продолжением recon. Также сохранены проверки Nuclei на положительном и отрицательном примерах, foreground service и доступности 15 модулей в интерфейсе. ARM64 собран; физический телефон не тестировался.
