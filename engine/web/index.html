Nuclei · шаблоны и уровни

Читаем каталог шаблонов…

Эти протоколы используют прямые соединения и порты из шаблонов. HTTP-прокси не ограничивает их маршруты.

Полный снимок шаблонов входит в приложение. Code, headless и локальные проверки не исполняются. Все папки DAST и SSL сохранены с подписями upstream; выбранные режимы и ограничения видны в «Покрытии».

Агенты и скорость

Агенты — обычные исполнители очереди, без ИИ. Число ограничивается доступной памятью. Настройка запросов/сек. делится между исполнителями; каждый модуль имеет общий бюджет времени.

Censys · пассивный OSINT

Нужен доступ к Censys Platform API. Запросы расходуют квоту аккаунта. Найденные IP остаются пассивными активами.

DAST · формы и запросы

POST-формы могут менять данные. Для точного покрытия API импортируй свои запросы с методом, URL, заголовками и телом.
